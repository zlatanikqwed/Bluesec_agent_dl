# BlueSec1 Agent


## Архитектура

Конвейер на одну задачу:

1. **Harvest** (`harvest_v31.py`) – код сам делает 8 запросов `search` вокруг триггера и собирает подграф: процессы, родители, потомки, сеть, файлы, учетные записи, хост.
2. **Расследователь** – gpt-oss-20b (открытые веса) в режиме SGR: каждый шаг – JSON по схеме. При необходимости дозапрашивает сущности и связи.
3. **Слепой аудитор** – та же модель с отдельным промптом заново оценивает факты, не видя первого вердикта.
4. **Арбитр** – крупная модель (Nemotron), вызывается только при расхождении или после проверки последствий benign. Если ее API недоступен, арбитраж делает основная модель.
5. **Детерминированные проверки** (`decision_guard.py`, `soc_v24.py`, `response_mapper.py`) ищут в графе решающие признаки атаки: выгрузку наружу, туннели, запуск из пользовательских каталогов, всплеск разведки и т. п. Проверки могут только поменять benign на malicious.
6. **Отчет** (`report_experiments.py`, режим `role_policy`) – чинит поля под схему и собирает артефакты атаки или доказательства легитимности.


## Структура репозитория

```
proto/                    runtime.proto – gRPC-контракт платформы
src/bluesec1_client/      клиент платформы: gRPC-транспорт, сессия, модели, сгенерированный proto
src/bluesec1_agent/       агент
scripts/                  офлайн-анализ траекторий и диагностика моделей
tests/                    pytest
pyproject.toml, uv.lock   зависимости (uv)
.env.example              пример конфигурации
```

### `src/bluesec1_agent/`

| Файл | Назначение |
| --- | --- |
| `cli.py`, `__main__.py` | точка входа `bluesec1-agent`: читает настройки, создает клиентов моделей и платформы, запускает прогон |
| `settings.py` | все параметры из `.env` (pydantic-settings) |
| `agent.py` | основной цикл `SimpleSGRAgent`: шаги модели, аудитор, арбитраж, финальные проверки |
| `llm.py` | OpenAI-совместимый клиент со структурированным выводом, восстановление невалидного JSON |
| `models.py` | pydantic-схемы инструментов и `finish_investigation` |
| `harvest_v31.py` | детерминированный сбор данных через `search` до вызова модели (используется) |
| `harvest_v32.py` | экспериментальный вариант Harvest → Judge → Report |
| `decision_guard.py` | решающие признаки атаки: утечка, туннели, место запуска, разведка |
| `response_mapper.py` | границы инцидента и меры реагирования, коды проверок с правом вето |
| `report_experiments.py` | варианты сборки отчета, финальный – `role_policy` |
| `security_engine.py`, `security_reasoning.py` | SOC-семантика событий Windows, PowerShell, AD, SMB, WinRM |
| `investigation_director.py` | вопросы-подсказки для небольшой модели |
| `inbound_evidence.py`, `external_peer_guard.py` | входящие удаленные входы и внешние узлы |
| `evidence_claims.py`, `evidence_workbench.py` | проверка утверждений модели по наблюдаемым фактам |
| `crawler.py` | детерминированный обход графа из ранних версий, сейчас нигде не импортируется |
| `soc_v18.py` … `soc_v24.py` | эволюция SOC-логики по версиям; v24 используется в поведенческой проверке |
| `benign_probe.py`, `probe_design.py`, `phaseL_evidence.py`, `research_harvest_v31.py` | исследовательские режимы фаз L–O (Practice), по умолчанию выключены |

### `scripts/`

| Файл | Назначение |
| --- | --- |
| `summarize_runs.py` | сводная таблица по прогонам: сумма Q×E, средние Q и E |
| `analyze_trajectories.py`, `_trajectories.py` | разбор траекторий, поиск зацикливаний |
| `analyze_arbiter.py` | где решал арбитр и чем он отличался от основной модели |
| `arbiter_smoke.py`, `arbiter_diag.py` | проверка модели-арбитра до прогона, диагностика пустых ответов |
| `llm_smoke.py`, `probe_models.py` | проверка доступности и задержки моделей |
| `analyze_*.py` | офлайн-анализ экспериментов отдельных фаз |
| `replay_*.py` | офлайн-повтор проверок на сохраненных траекториях без вызова модели и платформы |
| `generate_remote_proto.py` | генерация Python-кода из `proto/` |

### `tests/`

Тесты названы по версиям и фазам (`test_v9_…` – `test_v32_…`, `test_phaseC_…` – `test_phaseM_…`). Тесты последних изменений: `test_arbiter_model.py`, `test_egress_signals.py`, `test_execution_location.py`, `test_decision_guard.py`, `test_role_policy.py`.
